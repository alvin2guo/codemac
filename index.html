怎么玩？

1 输入 GitHub 用户名

只读取公开信息：资料、公开事件流、公开仓库。不需要登录，不需要授权，不存储任何数据。

2 代码 → 餐品换算

commit 变巨无霸、Star 变麦乐鸡、PR 变薯条、Issue 变可乐、Review 变玉米杯、粉丝变苹果片。

3 MCP 实时计价

调用麦当劳中国 MCP（mcp.mcd.cn）获取巨无霸等餐品实时价格，算出你的「巨无霸等价比」和餐饮账单，生成分享卡片。

命令行版本（实时 MCP 模式）

用自己的 MCP Token，实时取价生成卡片： 
# 1. 克隆仓库（零依赖，Node.js >= 18 即可）
git clone https://github.com/https://github.com/alvin2guo/codemac.git && cd codemac

# 2. 申请麦当劳 MCP Token：https://open.mcd.cn/mcp （手机号登录 → 控制台 → 激活）
export MCD_TOKEN=<你的 MCP Token>

# 3. 生成报告与分享卡片
node src/cli.js torvalds --out my-card.svg

# 启动本地演示站（实时模式）
MCD_TOKEN=<你的 MCP Token> node src/server.js
